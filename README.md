# Анализ сезонности продаж

Продуктовая аналитика: анализ сезонности выручки условного продавца
на маркетплейсе за 2024 год, с рекомендацией по планированию закупок.

## Задача

Данные о продажах за год по 5 категориям товаров. Нужно понять,
когда у каждой категории наступает сезонный пик, чтобы дать
рекомендацию по объёму и срокам закупок.

## Файлы в репозитории

- `sales.csv`, `products.csv` – исходные (сырые) данные: продажи
  и справочник товаров. Содержат некорректные
  записи (пропуски, аномалии, дубликаты).
- `analysis.sql` – полный SQL-скрипт: создание таблиц, разведочный
  анализ, поиск и устранение некорректных записей, агрегация по
  месяцам и категориям (PostgreSQL).
- `monthly_category_sales.csv` – результат SQL-агрегации, использован
  как источник данных для дашборда.
- `sales_seasonality_dashboard.pbix` – интерактивный дашборд (Power BI).
- `Sales seasonality report.pdf` – итоговый отчёт с выводами и
  рекомендацией по закупкам.

## Что сделано

- EDA и очистка данных: найдено и обработано 6 типов некорректных
  записей, включая пропуски
- Агрегация выручки и количества проданных единиц по месяцам и
  категориям через SQL (JOIN, GROUP BY, EXTRACT)
- Интерактивный дашборд в Power BI: динамика по месяцам, срез по
  категориям, ключевые показатели
- Бизнес-рекомендация по срокам и объёму закупок на основе найденной
  сезонности

## Результат

Общая выручка за год – 32,2 млн руб. Три из пяти категорий показывают
выраженные сезонные пики (март – «Красота и здоровье», ноябрь-декабрь –
«Электроника» и отчасти «Одежда»), требующие заблаговременного
планирования закупок, а не равномерного распределения по месяцам.
Полный разбор – в `Sales seasonality report.pdf`.

## Стек

PostgreSQL, SQL, Power BI
